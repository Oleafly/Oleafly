**在现代科学写作工作空间中，减少琐事，写好你的下一篇论文。**

Oleafly 是一款免费的桌面工作空间，用于通过 LaTeX、Typst 和 Markdown 撰写论文。你可以在同一处查找资料、管理引文，并看到论文逐步成形。让 AI 助手修改一个章节、制作一幅图，或修复失败的构建；你可以审阅每一项改动。项目保存在你拥有的普通文件中，编辑器可在启用或不启用 AI 的情况下使用。

## 功能

为下一次申请撰写学位论文、会议论文、实验报告或简历。选择 LaTeX、Typst 或 Markdown，并将整份文档放进同一个工作空间。

| 功能 | 你可以做什么 |
| --- | --- |
| **LaTeX、Typst 和 Markdown** | 在源文件旁查看 PDF 预览，并进行写作和编译。 |
| **模板和导入** | 新建论文、学位论文、报告、演示文稿或简历；也可以导入已有项目。 |
| **写作工具** | 补全命令、浏览章节、重命名引用，并在本地检查拼写和语法。 |
| **文献搜索** | 同时搜索多个学术索引，为正在写作的段落发现参考资料。 |
| **引文和文献库** | 导入文献库，按 DOI 或标题添加论文，并在写作时插入引文。 |
| **AI 协助** | 使用项目中的文件修改章节、修复构建或创建图形。 |
| **研究任务 · beta** | 在单独的副本中运行工作，审阅结果，并选择要应用的文件。 |
| **研究技能** | 进行文献综述、主张核查、数据分析和审稿意见回复。 |
| **图形和图表** | 在画布上绘制、编辑 TikZ，并在插入前预览编译后的图形。 |
| **投稿检查** | 检查参考文献、版式、匿名评审细节、无障碍性和简历解析。 |
| **检查点和 Git** | 恢复保存的项目状态，并管理提交、diff 和 GitHub 同步。 |
| **链接文件夹** | 向助手授予只读权限，以访问计算机其他位置的论文或数据。 |
| **导出** | 保存 PDF 和源代码 ZIP；支持的项目类型还可导出为文档、演示文稿和电子书。 |

### 从需要的文档开始

选择一篇期刊论文、一部学位论文、一份 Beamer 演示文稿或一份可以改成自己内容的简历。模板库包含 LaTeX、Typst 和 Markdown 起始项目，并提供预览，帮助你在写作前选定版式。

已经有手稿了吗？导入项目 ZIP 或 GitHub 仓库，带入 Word 文档，或将 PDF 作为可编辑 LaTeX 的起点。下一个项目可以从你已经完成的工作开始。

### 查看整份文档并写作

将源文件、章节大纲和已编译的 PDF 放在一起。你可以在章节间跳转，跟随引用找到定义，并在整个项目中重命名引文键。在 LaTeX 中，命令建议会依据所用的包变化；拼写和语法检查则聚焦于正文。

可以直接在源文件中写作，也可以使用 LaTeX 和 Markdown 的可视化编辑器。随着文档变长，公式、引文和图形仍随手可用。

<img src="../assets/readme/visual-editor.png" alt="Oleafly 可视化编辑器，同时显示文件树和文档大纲" width="100%" />

### 查找论证需要的资料

同时搜索 arXiv、Semantic Scholar、Crossref、PubMed 和 OpenAlex。Oleafly 会合并重复结果，并将你选择的论文保存到书目中。可从草稿中的一个段落开始搜索，找到尚未引用的相关研究。

从 Zotero RDF、EndNote XML、RIS 或 BibTeX 导入现有文献库。然后按 DOI 或标题添加参考文献，无须离开当前句子即可插入引文。


### 把真实项目交给助手

让助手精简一个章节、解释公式或修复构建。助手可以读取你的文件、编辑源文件、编译文档并检查结果。在请求中提到文件即可聚焦任务，也可以让它先给出计划。

继续使用你喜欢的模型：连接托管服务商、在本地使用 Ollama，或从下方选择一个 CLI 代理。关闭 AI 后，编辑器同样可以完整使用。

<img src="../assets/readme/ai-personas.png" alt="Oleafly AI 助手的写作和审阅角色选择" width="100%" />

</details>

### 将想法变成图形

向助手描述一个图表，或直接在画布上构建它。编辑 TikZ 源文件，单独编译图形，并在旁边查看渲染结果。具有视觉能力的模型可以检查该渲染结果，协助你调整版式。

插入结果时添加图注和标签。把可编辑的矢量源文件保留在项目中，为下一次修改或合作者的改动做好准备。

<img src="../assets/readme/diagram-composer.png" alt="Oleafly Diagram Composer 在画布上编辑图形" width="100%" />

### 研究推进时继续写作

将文献综述、分析或待修改的章节交给研究任务。任务会在项目的单独副本中运行，而你可以继续处理手稿。结果准备好后，逐个文件审阅，并应用你想保留的改动。

研究技能可以继续推进工作：建立阅读清单、根据原始资料核查主张、从论文准备演讲，或起草给审稿人的回复。也可以保存自己的流程，以便下一个项目再次使用。


### 准备要投稿的论文

导出前检查手稿和已编译的 PDF。预检会将未解决的参考文献、版式问题、草稿标记和匿名评审细节集中到一处；你可以从发现项回溯到源文件。

对于简历，检查 PDF 的文本如何进入解析器。对于论文，选择一个出版配置文件并审阅其投稿检查。准备发送时，导出 PDF 或打包源文件。

<img src="../assets/readme/preflight-accessibility.png" alt="Oleafly Preflight 无障碍检查结果" width="100%" />

### 让每个项目始终属于你

你的工作保存在计算机的普通文件中。可以在其他工具中编辑，与合作者共享，或放入 Git。无需持续支付 Oleafly 订阅费，才能打开自己的工作。

成功编译会保存自动检查点，因此可以回到项目的早期状态。需要提交和共享历史时，使用 Git。保留什么、何时发布，都由你决定。

## 工作空间的更多功能

### 从已有工作开始

创建研究项目、导入现有项目，或选择可编辑的模板。开始页面帮助你为论文、学位论文、报告、演示文稿和其他科学文档选择合适的起点。

<img src="../assets/readme/start-work.png" alt="Oleafly 开始页面，可选择研究项目、导入项目或模板" width="100%" />

### 使用 LaTeX、Typst 或 Markdown 编译

为每个项目选择引擎。Tectonic 随应用提供，适合便携式离线构建；`latexmk` 使用已有的 TeX 发行版；Typst 直接编译；Markdown 使用 Pandoc 进行转换。界面会显示当前引擎的实际能力。

<img src="../assets/readme/compile-engines.png" alt="Oleafly 中 LaTeX、Typst、Markdown 和 TeX 发行版的引擎设置" width="100%" />

### 同时阅读源文件和 PDF

源文件始终是主要表示形式，PDF 查看器则显示在旁边。引擎支持时，可以通过 SyncTeX 在源代码行和 PDF 页面之间跳转。编译失败不会自动替换最后一个可读的 PDF。

<img src="../assets/readme/source-and-pdf.png" alt="Oleafly 同时显示论文源文件和编译后的 PDF" width="100%" />
<img src="../assets/readme/pdf-preview.png" alt="Oleafly 源代码编辑器旁的 PDF 预览" width="100%" />

### 重用研究 Skills

Skills 是普通的 `SKILL.md` 文件夹，用于文献、写作、图形、审阅、投稿和其他工作流。可以用斜杠命令运行它们，保存有效的工作流，或与兼容的代理共享。

<img src="../assets/readme/skills.png" alt="Oleafly 中可重用的研究和写作工作流 Skills" width="100%" />

内置的 `research-core` 软件包包含 36 个 Skills。完整的[内置 Skills 列表](../../README.md#skills-shipped-with-oleafly)和目录名称请参阅英文 README。

### 在一个工具库中查找工具和命令

工具库包含 PDF、arXiv、图像、HTML、Word、Markdown、Typst、表格和公式转换工具，也包括 BibTeX、文献、统计、写作、实验室和会议工具。命令面板可以搜索项目、文档、设置和工具；输入 `/` 可只筛选命令。

<img src="../assets/readme/command-palette.png" alt="Oleafly 命令面板，可搜索项目、文档、命令和工具" width="100%" />
<img src="../assets/readme/tools-gallery.png" alt="Oleafly 工具库，展示研究和文档工具" width="100%" />

### 在论文旁边使用终端

每个项目最多可打开十个 Shell 标签页，为它们命名，并在当前文件夹中运行脚本、数据分析或其他 CLI 工具。内置浏览器用于 computer use 任务，并与论文窗口分开。

<img src="../assets/readme/project-terminal.png" alt="Oleafly 在论文项目旁打开终端" width="100%" />

### 提供商连接由你明确选择

项目文件、索引、本地编译、PDF 预览、检查、Git 和检查点都留在你的电脑上。只有在你选择文献搜索、GitHub、托管 AI 或下载等操作时才会访问网络。本地 Ollama 模型会让模型通信留在你的电脑上。

<img src="../assets/readme/provider-boundaries.png" alt="Oleafly 提供商设置与项目文件分开" width="100%" />

## 随工作一起成长的工作空间

Oleafly 希望成为一个相连的研究工作空间：塑造问题的阅读材料、支撑结果的分析、解释结果的论文，以及分享成果的演讲。

路线图接下来包括实时协作与评论、多语言界面、更深入的 Typst 和 Markdown 支持，以及可选的跨设备同步。可在[更新日志](../../CHANGELOG.md)中关注这些工作的进展。

Oleafly 由 [Prajwal Murthy](https://github.com/prajwal-svm) 和贡献者共同构建。模板、代码、文档，以及你对自己写作的反馈，都在帮助项目不断完善。阅读[贡献指南](../../CONTRIBUTING.md)以参与其中。

如果 Oleafly 让你的写作更轻松，[在 GitHub 上点一颗⭐](https://github.com/Oleafly/Oleafly)，帮助更多研究者发现它。

### 引用 Oleafly

如果 Oleafly 帮你完成了一篇论文，请引用它。在参考文献里加入一条 BibTeX 条目，就能让下一位研究者知道这个工具的来历，也让一个免费开源项目继续被看见：

```bibtex
@software{oleafly,
  author  = {Venkateshmurthy, Prajwal S and {The Oleafly contributors}},
  title   = {Oleafly: a local-first desktop workspace for research writing},
  year    = {2026},
  version = {0.4.1},
  url     = {https://github.com/Oleafly/Oleafly},
  license = {AGPL-3.0-or-later}
}
```

仓库页面顶部的 **Cite this repository** 按钮提供同一条引用的 APA 和 BibTeX 版本，由 [CITATION.cff](../../CITATION.cff) 生成。应用内的设置、帮助与关于中有复制按钮。
