# Bundled citation styles

Oleafly includes selected styles from the official Citation Style Language repository so references can be formatted without sending document data anywhere.

The files in this folder were retrieved from `citation-style-language/styles` at commit `baa973a801cefe884aa37105927b3e24ccc07daf`. Each style retains its original authorship and license metadata and is available under the Creative Commons Attribution-ShareAlike 3.0 license.
