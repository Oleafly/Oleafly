# Pandoc 3.9.0.2 source code

Oleafly ships Pandoc 3.9.0.2 as a separate, unmodified executable and starts
it as its own process for document conversion. Pandoc is licensed under the
GNU General Public License, version 2 or later. The full license text is in
`pandoc-3.9.0.2-COPYING.md` next to this file.

The complete source code for this exact version is published by the Pandoc
project:

- Tag: https://github.com/jgm/pandoc/tree/3.9.0.2
- Archive: https://github.com/jgm/pandoc/archive/refs/tags/3.9.0.2.tar.gz

Oleafly's own source, including the script that downloads and checks the
Pandoc release archives, is at https://github.com/Oleafly/Oleafly. The
SHA-256 digests of the bundled archives are listed in that repository's
`THIRD_PARTY_LICENSES.md`.

If you cannot reach those addresses, write to the Oleafly maintainers through
the repository and a copy of the source will be provided.
