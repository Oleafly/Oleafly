# My Template

One paragraph: what this template is for, who should reach for it, and what it looks like.

## What you get

- `main.tex`, the document you edit
- `refs.bib`, the bibliography (delete it if you are not citing anything)

## Fill these in first

| Where | What |
|---|---|
| `\title{...}` | The working title |
| `\author{...}` | Authors and affiliations |
| The abstract | One paragraph, written last |
| Each `\section` | Replace the placeholder prose |
| `refs.bib` | Your real entries |

## Engine

Compiles with the bundled Tectonic engine. Nothing to install, and it works offline once the TeX bundle has been fetched once.
