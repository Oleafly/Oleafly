\begin{abstract}
Long-context transformer inference is bounded by attention memory traffic
rather than arithmetic. We present \sysname, a scheduler that partitions the
attention matrix into fixed blocks, predicts block importance from a cheap
low-rank probe, and evicts provably negligible blocks before they reach the
accumulator. On a single 24\,GB consumer accelerator, \sysname{} serves
128k-token contexts that otherwise exhaust device memory, and reduces median
time to first token by 2.7 times against a dense FlashAttention baseline while
holding perplexity within 0.4 percent. We characterise where the approximation
becomes unsafe and give a runtime guard that falls back to dense computation
for the affected heads.
\end{abstract}
